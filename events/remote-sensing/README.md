# Remote Sensing

Science Olympiad Division B

Season: 2026–2027

## Event Overview

Remote Sensing focuses on understanding how remote sensing is used to observe and study Earth.

Participants will work with remote sensing concepts, imagery, data, and maps.

## Main Topics

- Light and Remote Sensing
- Sensors
- Satellite Orbits
- Image Resolution
- Mapping Fundamentals
- Measurements
- Image Interpretation
- Earth Observation and Monitoring
- Land Cover Classification
- Environmental and Human Impacts

## Equations

- Wien's Displacement Law
- Wave Equation
- Snell's Law
- Inverse-Square Law for Irradiance
- Stefan-Boltzmann Law
- Radar Altimetry Range
- Kepler's Third Law

## Satellites and Data Sources

- Landsat 5–9
- Sentinel-1A/1B
- Sentinel-2A/2B
- Terra
- SRTM
- ECOSTRESS
- GOES
