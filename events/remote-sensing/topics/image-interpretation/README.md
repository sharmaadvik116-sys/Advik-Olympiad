# Image Interpretation

Science Olympiad Division B — Remote Sensing

## Image Display Types

Be able to interpret:

- Natural color
- False color
- Grayscale
- Thermal
- Radar
- Elevation
- Contour
- Classified map displays

## Image Interpretation

Practice identifying patterns, features, and changes in remote sensing images and data.

Pay attention to:

- Color and brightness
- Spatial patterns
- Land cover
- Elevation
- Temperature
- Vegetation
- Changes over time

## Earth Observation

Remote sensing can be used to observe and monitor:

- Vegetation changes
- Land cover changes
- Urbanization
- Deforestation
- Flooding
- Wildfires
- Landslides
- Volcanoes
- Glacial movement
- Fluvial processes
- Elevation or subsidence changes

## Land Cover Classification

Understand the basic difference between:

- Supervised classification
- Unsupervised classification

Be able to interpret classification maps and identify what the displayed categories represent.

## Science Olympiad Focus

Be able to:

- Interpret different remote sensing image displays.
- Identify features from images.
- Compare images and data.
- Recognize changes over time.
- Connect image patterns with Earth processes.
- Interpret land cover classification maps.
- Use remote sensing information to understand environmental changes.

## Practice

Practice interpreting satellite images, aerial photographs, radar images, thermal images, elevation products, contour displays, and classified maps.
