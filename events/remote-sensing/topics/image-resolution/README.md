# Image Resolution

Science Olympiad Division B — Remote Sensing

## Types of Resolution

Remote sensing images can be described using different types of resolution.

### Spatial Resolution

Describes the size of the area represented by each pixel.

Higher spatial resolution allows smaller features to be distinguished.

### Temporal Resolution

Describes how frequently a sensor can observe the same area.

Higher temporal resolution means observations can be made more frequently.

### Spectral Resolution

Describes how finely a sensor can distinguish different wavelength ranges.

### Radiometric Resolution

Describes how sensitively a sensor can distinguish differences in the intensity of detected energy.

The event specifically includes:

- Signal-to-noise ratio (SNR)
- Sensitivity

## Science Olympiad Focus

Be able to:

- Distinguish spatial, temporal, spectral, and radiometric resolution.
- Determine which type of resolution is being described in a question.
- Compare images or sensors based on their resolution characteristics.
- Understand how resolution affects interpretation of remote sensing data.

## Practice

Practice identifying the type of resolution from descriptions, images, sensor specifications, and remote sensing examples.
