
# Land Cover Classification

Science Olympiad Division B — Remote Sensing

## Classification Maps

Remote sensing data can be used to create maps that classify different types of land cover.

## Classification Methods

The event includes:

- Supervised classification
- Unsupervised classification

## Supervised Classification

Understand the basic idea of using known or labeled examples to help classify areas in an image.

## Unsupervised Classification

Understand the basic idea of grouping areas based on similarities in the remotely sensed data.

## Land Cover Change

Classification can be used to study changes in land cover over time.

Examples include:

- Forest changes
- Agricultural changes
- Urbanization
- Deforestation
- Habitat loss

## NLCD / CONUS Land Cover Change Index

The event specifically includes the:

- National Land Cover Database (NLCD/CONUS)
- Land Cover Change Index

Be able to interpret information presented using these land-cover datasets.

## Science Olympiad Focus

Practice:

- Identifying supervised and unsupervised classification.
- Interpreting classification maps.
- Comparing land-cover categories.
- Identifying land-cover changes.
- Connecting land-cover changes with environmental and human impacts.

## Practice

Practice interpreting classified maps and comparing land-cover information from different dates or locations.
