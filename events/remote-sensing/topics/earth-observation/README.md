
# Earth Observation and Monitoring

Science Olympiad Division B — Remote Sensing

## What Is Earth Observation?

Remote sensing data can be used to observe and monitor changes on Earth's surface and in the environment.

## Physical Phenomena

The event includes interpretation of:

- Absorption and scattering by aerosols
- Albedo
- Surface temperature
- Reflectance
- Elevation and subsidence changes
- Vegetation changes
- Geohazards
- Earth processes

## Geohazards

Remote sensing can be used to monitor:

- Volcanoes
- Landslides
- Flooding
- Wildfires

## Earth Processes

Examples include:

- Glacial movement
- Fluvial processes
- Stream patterns

## Vegetation and Land-Cover Change

Remote sensing can help identify changes involving:

- Forests
- Agriculture
- Vegetation
- Other land-cover changes

## Science Olympiad Focus

Practice interpreting remote sensing data to identify:

- Environmental changes
- Changes in land cover
- Changes in elevation
- Changes in vegetation
- Natural hazards
- Earth-surface processes

## Practice

Practice comparing remote sensing images and datasets to identify physical changes and environmental patterns.
