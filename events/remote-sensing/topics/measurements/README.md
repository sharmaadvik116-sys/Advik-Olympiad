# Measurements

Science Olympiad Division B — Remote Sensing

## Measurements in Remote Sensing

The event includes measurements and scaling estimates from maps, satellite images, aerial photographs, and other remotely sensed data.

## Measurements to Know

- Distance between features
- Perimeter
- Area
- Altitude
- Elevation
- Slope
- Gradient

## Map Scale

Use the scale provided on a map or image to estimate real-world measurements.

Be careful to distinguish:

- Map distance
- Real-world distance
- Elevation
- Altitude

## Slope and Gradient

Be able to interpret slope or gradient from elevation information.

Pay attention to the relationship between:

- Change in elevation
- Horizontal distance
- Steepness of the terrain

## Science Olympiad Focus

Be able to:

- Measure distances between features.
- Estimate perimeter and area.
- Interpret altitude and elevation.
- Use map scales.
- Interpret slope and gradient.
- Apply measurements to maps and remotely sensed images.

## Practice

Practice using scales, map measurements, elevation information, and image data to estimate real-world distances and other measurements.
