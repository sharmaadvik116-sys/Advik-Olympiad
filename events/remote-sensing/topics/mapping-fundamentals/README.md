# Mapping Fundamentals

Science Olympiad Division B — Remote Sensing

## Types of Maps and Images

Remote sensing information can be presented as:

- Topographic maps
- Satellite images
- Aerial photographs
- Maps generated from remotely sensed data

## Marginal Information

Be able to identify and interpret:

- Location
- Date
- Scale
- Orientation
- Legend
- Labels

## Map Reading

Practice using the information provided on a map or image to understand what is being represented.

Pay attention to:

- Map scale
- Direction and orientation
- Symbols and legends
- Locations and labels
- Elevation information

## Image Display

Remote sensing information may be displayed in different ways, including:

- Natural color
- False color
- Grayscale
- Thermal
- Radar
- Elevation
- Contour
- Classified map displays

## Science Olympiad Focus

Be able to:

- Identify the type of map or image being used.
- Use marginal information to interpret a map.
- Read scale, legends, labels, and orientation.
- Understand what different image displays represent.
- Compare information shown in different map or image formats.

## Practice

Practice interpreting maps, satellite images, aerial photographs, legends, scales, orientations, and different remote sensing image displays.
