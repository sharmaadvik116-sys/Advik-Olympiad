
# Human and Environmental Implications

Science Olympiad Division B — Remote Sensing

## Remote Sensing and Environmental Change

Remote sensing can help monitor changes to Earth's surface and identify environmental and human impacts.

## Important Topics

- Habitat loss
- Land cover change
- Urbanization
- Deforestation
- Damage assessment
- Environmental monitoring

## Habitat Loss

Remote sensing can be used to identify changes in land cover that may affect habitats.

## Urbanization

Changes in developed areas can be observed by comparing remote sensing images and land-cover data over time.

## Deforestation

Remote sensing can help identify changes in forested areas and monitor changes over time.

## Damage Assessment

Remote sensing can support monitoring and assessment of areas affected by events such as:

- Flooding
- Wildfires
- Landslides
- Other environmental hazards

## Science Olympiad Focus

Practice connecting remote sensing observations with:

- Environmental changes
- Human activities
- Land-cover changes
- Habitat changes
- Damage assessment

## Practice

Compare remote sensing images or classified maps from different times and identify the environmental or human changes shown.
