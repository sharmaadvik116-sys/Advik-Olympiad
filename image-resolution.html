What Is Image Resolution?

Resolution describes how much detail a remote sensing system can distinguish or how frequently it can collect observations.

Four important types: spatial, temporal, radiometric, and spectral resolution.

Spatial Resolution

Spatial resolution describes the size of the smallest area represented by an individual image pixel.

A smaller pixel size generally allows finer spatial details to be seen.

Example: A sensor with smaller pixels may distinguish individual buildings more clearly than a sensor with much larger pixels.

Temporal Resolution

Temporal resolution describes how frequently a sensor can observe the same location.

  • High temporal resolution → observations are made more frequently.
  • Low temporal resolution → more time passes between observations.
Useful for: Monitoring changes such as vegetation, floods, fires, or other events.

Radiometric Resolution

Radiometric resolution describes how sensitively a sensor can distinguish differences in measured energy.

Signal-to-noise ratio is important when considering how reliably a sensor can distinguish a signal from background noise.

Spectral Resolution

Spectral resolution describes how finely a sensor can distinguish different wavelength ranges.

A sensor with many narrow spectral bands can provide detailed information about how materials interact with different wavelengths.
