What Is a Remote Sensing Map?

Remote sensing data can be displayed as maps, satellite images, aerial photographs, elevation products, and other geographic displays.

Key idea: Always examine the map information before interpreting the image.

Marginal Information

Maps and images often contain information around the main display. This information helps the user understand what the image represents.

  • Location
  • Date
  • Scale
  • Orientation
  • Legend
  • Labels

Scale

Scale relates distances shown on a map to actual distances on Earth.

Example: If a map scale tells you that a certain map distance represents 1 kilometer, you can use that relationship to estimate distances between features.

Orientation

Orientation tells you how the map is positioned relative to geographic directions.

A north arrow is a common way to identify orientation.

Legend

A legend explains symbols, colors, patterns, or classes used in a map.

Never assume that a color has a particular meaning without checking the legend.

Types of Displays

  • Topographic maps
  • Satellite images
  • Aerial photographs
  • Elevation maps
  • Contour maps
  • Classified maps
